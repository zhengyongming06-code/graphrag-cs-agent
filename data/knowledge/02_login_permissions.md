# 账号登录与权限问题排查

## 常见问题：登录失败
1. 确认邮箱已完成激活（查收激活邮件，检查垃圾箱）。
2. 若开启 SSO，请走企业 IdP 入口，不要使用本地密码登录。
3. 连续失败 5 次会触发 15 分钟锁定，可联系主管理员解锁。
4. 重置密码后，旧会话 Token 会失效，需重新登录所有终端。

## 权限不足
NovaDesk 角色包括：Owner、Admin、Agent Lead、Agent、Viewer。
- 只有 Admin/Owner 可修改知识库与计费规则。
- Agent 默认可处理工单，不可导出全量客户数据。
- 若提示「权限不足」，请主管理员在「组织设置 → 成员」中调整角色。

## API 报错
调用 Open API 出现 401：检查 Access Key 是否过期；出现 403：检查 IP 白名单与 scope。
同步延迟通常来自 Webhook 重试队列堆积，可在「开发者中心 → 投递日志」查看。
